# 🚀 YouTube Alog Website

Welcome to the **YouTube Alog** repository! This project contains a modern, responsive, single-file web application built for content creators, video editors, and digital entrepreneurs.

## 🌟 Features

* **Responsive Design**: Built using Tailwind CSS, optimized across desktop, tablet, and mobile views.

* **Dark Mode Support**: Light and Dark mode toggles with automatic theme state handling.

* **Interactive Creator Tools**:

  * **Title & Tag Generator Simulator**: Generate high-CTR titles and SEO tags for video topics.

  * **Channel Launch Checklist**: Interactive progress bar tracking pre-upload requirements.

* **Software & Gear Matrix**: Evaluates software (CapCut, VidIQ, OBS) and camera/audio gear.

* **AdSense Ready**: Pre-formatted structural placeholders for ad banners and privacy policies.

## 🚀 Quick Start & Deployment on GitHub Pages

You can host this entire website for free using **GitHub Pages**:

1. **Fork or Clone this repository**:

   ```
   git clone https://github.com/your-username/youtube-alog.git
   
   ```

2. **Upload/Verify `index.html`**:
   Ensure `index.html` is in the main root directory of the repository.

3. **Enable GitHub Pages**:

   * Go to **Settings** > **Pages** in your GitHub repository.

   * Under **Build and deployment**, set **Source** to `Deploy from a branch`.

   * Select the **`main`** (or `master`) branch and set folder to `/(root)`.

   * Click **Save**.

4. **Access your website**:
   Your site will be live at `https://<your-username>.github.io/youtube-alog/` in under 1-2 minutes!

## ⚙️ Customization & AdSense Integration

* **Google AdSense**:
  To add your AdSense ads, uncomment the script tag in the `<head>` section of `index.html` and replace `ca-pub-XXXXXXXXXXXXXXXX` with your actual AdSense Publisher ID:

  ```
  <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-YOUR_ADSENSE_ID" crossorigin="anonymous"></script>
  
  ```

* **Domain Setup**:
  If connecting a custom domain (e.g., `youtubealog.com`), add your custom domain in the **Settings > Pages > Custom Domain** section of GitHub.
